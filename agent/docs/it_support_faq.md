Frequently Asked Questions
--------------------------

1. How do I request new developer software or cloud licenses?
-------------------------------------------------------------
Submit a Service Desk ticket under the "Software License Request" category. Licenses for standard developer tools (JetBrains IDEs, Docker Desktop Pro, GitHub Copilot) are pre-approved for engineering staff. AWS or GCP sandbox accounts require approval from Dr. Vikram Malhotra.

2. What should I do if I lose my YubiKey or MFA device?
-------------------------------------------------------
Immediately contact IT Security via Slack (`it-security-urgent`) or call the emergency IT helpline. Neha Sharma or an on-duty administrator will revoke existing session tokens and issue a temporary one-time bypass code after verifying your identity over video call.

3. How do I connect my phone or personal tablet to office Wi-Fi?
----------------------------------------------------------------
Personal devices (BYOD) are only permitted on the isolated network `Acme-Guest`. They are not allowed on `Acme-Corp-Secure`. Note that guest network access vouchers must be collected from the front desk reception; credentials are not listed online.

4. What is the standard hardware refresh cycle?
-----------------------------------------------
Laptops are refreshed every 3 years. If your device experiences critical hardware failures or physical damage, file an RMA ticket with IT Support.

5. Can I use external USB monitors or storage devices?
------------------------------------------------------
- External monitors connected via HDMI or USB-C DisplayPort are supported without prior ticket approval.
- USB flash drives and external hard drives are blocked by default on all company OS images. If you require access to transfer calibration datasets or flash robot microcontrollers, submit an "Endpoint Security Exemption" ticket.
